# 《潮间潜客》 / Tide Diver — 3D 原创美术

使用 Godot 原生网格生成低多边形 3D 海洋，无外部图片、下载资产或第三方角色。所有源文件和运行输出均留在项目盘。

美术使用深青海水、暖橙珊瑚、薄荷绿海草、奶油色砂石和金色潜水装备。潜水员穿橙色潜水服，带黄色气瓶、黄色脚蹼和青色面罩；工作船具有绿白条纹顶棚与下水梯。角色和场景均为原创。

世界范围 x/z ±65，海面 y=0，海底 y=-55。多层悬浮礁石从浅海延伸至深处，中央保留游动空间。海底有发光铭文古代门、倒塌石柱、路径、沉船、珊瑚与荧光菌群，便于立体探索和方向辨识。低多边形岩柱围绕外圈，场景中央附近亦有充足装饰。

`scripts/ocean_art.gd` 提供 `build_world(parent)`、`create_diver()`、`create_fish(kind)`、`create_pickup(kind)`、`create_boat()`。角色面向本地 -Z；世界自带海床、主要岩石、石柱和沉船船底的简化静态碰撞；摄像机和环境光由主程序统一设置。鱼尾节点名 `Tail`，潜水员脚蹼所在节点为 `LegLeft` 与 `LegRight`，可由主程序动画控制。

当前玩法使用三种鱼模型：金色、青绿、珊瑚橙；美术函数另保留灰蓝鲨形和砂金配色供后续扩展。拾取物：珍珠贝、宝箱、氧气瓶。


海面使用双面半透明程序化波纹 Shader，位于 y=0.6。五束宽而淡的透明光柱带边缘与高度衰减，不产生碰撞或阴影。两者均由代码生成材质，无外部纹理。


## 海岸餐厅美术（V0.2）

新增 `scripts/restaurant_art.gd`，为可实时装修的三维海岸小店截面。奶油色墙面、薄荷绿窗框和橱柜、暖木地板，与潜水世界共享原创低多边形造型。外景包含沙滩、远处海面、棕榈、木露台与低绳栏。

六项装修有独立可见变化：清理会移除旧木板、纸箱和垃圾并修复地板与墙面；厨房增加料理台、灶具、水槽、调料、餐具与厨师；基础桌椅增加两张圆桌；招牌增加双语 TIDE TABLE / 潮间食堂发光门头；扩座增加两张圆桌；软装增加地毯、绿植、灯串、装饰画和救生圈。默认旧店没有厨房或餐桌。

餐厅以局部中心为原点，宽 14、深 11，地板 y=0，后墙 z=-5.35，入口朝 +Z。低侧墙与开放屋顶保留俯视经营视野。无行走碰撞，无单独全局环境，仅局部暖灯。主流程可将根节点放到世界 (180,0,0)，相机从局部 (15,12,18) 看向 (0,1,0)。

接口：`rebuild(renovation)` 仅在装修改变时重建静态店面；`set_customers(orders)` 按订单 id 稳定创建、更新和移除顾客，不整店重建；`animate(delta)` 提供轻微呼吸与头部动作。四个服务座位固定编号 0–3。顾客使用不同服装与肤色，头顶显示座位和订单状态；完成菜品出现在厨房出餐台，顾客离店后移除。

所有模型、字体配置与材质由代码生成；中文文字使用 SystemFont 读取系统已安装中文字体，不下载或写入 C 盘资源。

## 自由布置与材质风格（V0.3）

`rebuild(renovation, furnishings = [], styles = {})` 保留旧调用方式。传入非空家具数组时，室内桌椅、盆栽、地毯、落地灯、陈列架完全由各条目的 `placed`、`x/z`、`rotation`、`color` 决定。模型节点命名为 `Furniture_<uid>`；家具支持四个直角朝向与暖木、薄荷、珊瑚三种配色。桌椅作为完整家具组旋转，模型保持在 2.5×3.8 米占地内。露台绿植、灯串与墙饰仍属于基础软装。

地板可选暖木、浅砂、海绿三种颜色，墙面可选奶油、浅薄荷、暖珊瑚。地板与墙色由 `styles.floor` / `styles.wall` 的 0–2 索引控制。

顾客座位按家具原数组顺序筛选已摆放桌子，沿用基础两桌、扩建四桌上限；人物跟随桌子的平移与旋转。厨房出餐盘使用独立节点，不受顾客或桌子旋转影响。

布置辅助接口：`set_layout_preview(kind, pos, rotation, color, valid)` 提供半透明家具预览和占地边框，绿色表示可放、红色表示不可放；相同参数直接复用缓存。`clear_layout_preview()` 清除预览；`set_layout_grid(enabled)` 控制半米网格与中央保留通道；`highlight_furniture(uid)` 用金色占地边框标识选中家具。辅助绘制只作用于独立节点，不重建整间餐厅。
