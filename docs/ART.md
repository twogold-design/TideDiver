# 《潮间潜客》 / Tide Diver — 3D 原创美术

## 角色细化（2026-10-26）

`scripts/diver_art.gd`接管潜水员建模，原`OceanArt.create_diver()`入口及`LegLeft`/`LegRight`动画节点不变。橙色潜水服增加轮廓与接缝、分体面罩与眼睛、呼吸器和弯曲软管、圆头气瓶与双绑带/扣件/阀门、腕表、分指手套、膝部护垫、潜水靴、带筋条的渐宽脚蹼，以及鱼枪握把、线轮与弹力带。

`scripts/restaurant_person.gd`细化脸部与下颌轮廓、眼白/虹膜/瞳孔/高光/上眼睑、耳廓、鼻翼、嘴唇及发束，顾客按身份使用五种发型。服装增加成形衣身、衣领、纽扣门襟、胸袋、袖口、布料纹理、围裙口袋与缝线、腰带和侧挂擦手巾、褶皱厨师帽，手部拆分手指与拇指，裤腿和鞋加入缝线、翻边、鞋底及鞋带。

`scripts/character_geometry.gd`提供椭圆截面造型与软管细节；复用家具材质缓存和静态网格合批，在各骨架关节内部合并同材质部件。眼睛改为独立节点内的多层网格，眨眼缩放整个眼节点；头、肩肘、髋膝、表情与刀勺叉盘仍独立动作，不添加独立时钟或TIME材质。保持程序化风格，未引入下载资源。

近景：[主厨与五位顾客](../artifacts/character_people_detail.png)、[潜水员装备](../artifacts/character_diver_detail.png)；实际镜头：[潜水](../artifacts/character_dive_gameplay.png)、[营业](../artifacts/character_restaurant_gameplay.png)。前两张是实际模型的展示镜头。完整回归1,029项通过，包含原有动作与暂停验证。以下保留历次场景说明。


使用 Godot 原生网格生成低多边形 3D 海洋，无外部图片、下载资产或第三方角色。所有源文件和运行输出均留在项目盘。

美术使用深青海水、暖橙珊瑚、薄荷绿海草、奶油色砂石和金色潜水装备。潜水员穿橙色潜水服，带黄色气瓶、黄色脚蹼和青色面罩；工作船具有绿白条纹顶棚与下水梯。角色和场景均为原创。

当前可游范围 x/z ±500米、深度上限120米；海面和地形向边界外延伸200米。海床由49块网格组成，沙坡、陆架与海沟共用相同顶点生成显示和碰撞。近岸保留珊瑚、遗迹和沉船，六处远海目的地在起伏地形上放置地标与资源。

`scripts/ocean_art.gd` 提供 `build_world(parent)`、`create_diver()`、`create_fish(kind)`、`create_pickup(kind)`、`create_boat()`。角色面向本地 -Z；世界自带海床、主要岩石、石柱和沉船船底的简化静态碰撞；摄像机和环境光由主程序统一设置。鱼尾节点名 `Tail`，潜水员脚蹼所在节点为 `LegLeft` 与 `LegRight`，可由主程序动画控制。

当前九种鱼均由 `scripts/fish_art.gd` 构建，`OceanArt.create_fish(kind)` 为统一入口。通过轮廓与结构区分橘鳍鱼的条纹、青背鱼的银线、灯笼鱼的发光诱饵、沙丁鱼的细身、河豚的圆身与棘刺、狮子鱼的扇鳍、金枪鱼的纺锤体与黄色小鳍、海鳗的分节长身、灰礁鲨的吻部和背鳍。海鳗的尾部关节依次摆动，河豚防御时实际膨胀。拾取物保持珍珠贝、宝箱和氧气瓶。


海面使用双面半透明程序化波纹 Shader，位于 y=0.6。五束宽而淡的透明光柱带边缘与高度衰减，不产生碰撞或阴影。两者均由代码生成材质，无外部纹理。


## 海岸餐厅美术（V0.2）

新增 `scripts/restaurant_art.gd`，为可实时装修的三维海岸小店截面。奶油色墙面、薄荷绿窗框和橱柜、暖木地板，与潜水世界共享原创低多边形造型。外景包含沙滩、远处海面、棕榈、木露台与低绳栏。

六项装修有独立可见变化：清理会移除旧木板、纸箱和垃圾并修复地板与墙面；厨房增加料理台、灶具、水槽、调料、餐具与厨师；基础桌椅增加两张圆桌；招牌增加双语 TIDE TABLE / 潮间食堂发光门头；扩座增加两张圆桌；软装增加地毯、绿植、灯串、装饰画和救生圈。默认旧店没有厨房或餐桌。

餐厅以局部中心为原点，宽 14、深 11，地板 y=0，后墙 z=-5.35，入口朝 +Z。低侧墙与开放屋顶保留俯视经营视野。无行走碰撞，无单独全局环境，仅局部暖灯。主流程可将根节点放到世界 (180,0,0)，相机从局部 (15,12,18) 看向 (0,1,0)。

接口：`rebuild(renovation)` 仅在装修改变时重建静态店面；`set_customers(orders)` 按订单 id 稳定创建、更新和移除顾客，不整店重建；`animate(delta)` 提供轻微呼吸与头部动作。四个服务座位固定编号 0–3。顾客使用不同服装与肤色，头顶显示座位和订单状态；完成菜品出现在厨房出餐台，顾客离店后移除。

所有模型、字体配置与材质由代码生成；中文文字使用 SystemFont 读取系统已安装中文字体，不下载或写入 C 盘资源。

## 自由布置与材质风格（V0.3）

`rebuild(renovation, furnishings = null, styles = {})` 保留旧调用方式。传入家具数组时（显式空数组代表空屋，仅省略参数或null时使用旧版默认布置），室内桌椅、盆栽、地毯、落地灯、陈列架完全由各条目的 `placed`、`x/z`、`rotation`、`color` 决定。模型节点命名为 `Furniture_<uid>`；家具支持四个直角朝向与暖木、薄荷、珊瑚三种配色。桌椅作为完整家具组旋转，模型保持在 2.5×3.8 米占地内。灯串与墙饰仍属于基础软装。

地板可选暖木、浅砂、海绿三种颜色，墙面可选奶油、浅薄荷、暖珊瑚。地板与墙色由 `styles.floor` / `styles.wall` 的 0–2 索引控制。

顾客座位按家具原数组顺序筛选已摆放桌子，沿用基础两桌、扩建四桌上限；人物跟随桌子的平移与旋转。厨房出餐盘使用独立节点，不受顾客或桌子旋转影响。盆栽统一由已摆放家具生成，软装不再额外生成固定露台盆栽。

布置辅助接口：`set_layout_preview(kind, pos, rotation, color, valid)` 提供半透明家具预览和占地边框，绿色表示可放、红色表示不可放；相同参数直接复用缓存。`clear_layout_preview()` 清除预览；`set_layout_grid(enabled)` 控制半米网格与中央保留通道；`highlight_furniture(uid)` 用金色占地边框标识选中家具。辅助绘制只作用于独立节点，不重建整间餐厅。

## 空间与家具品质升级（V0.4）

餐厅扩大至 22 米宽，主地板覆盖 z=-5.5 到 9.5，前露台与海岸同步延伸。可布置区域直接读取 `LayoutRules`，目前为 x±10.3、z=-2.45～9.4，中央通道半宽 0.6 米。厨房位置保留，家具保持原有实际尺寸。

新增 `scripts/furniture_art.gd`，静态接口 `build(item, seat=-1) -> Node3D` 同时服务餐厅与商店实物预览。返回以本地原点为中心的完整模型；由调用者设置平移和旋转。`item.variant` 支持 basic / comfort / premium，旧数据默认 basic。模型名与 meta 保留 uid/kind/variant。

## V0.5 人物与外海

人物使用原创程序化关节模型：肩肘、髋膝、头部与躯干分离，面部、头发和厨师帽附着头节点；厨房动作由真实订单驱动，顾客情绪由实际耐心比例驱动。所有动作只由餐厅animate(delta)推进，无独立计时器；暂停冻结，重开清理。离席反馈在独立露台播放以释放桌位。气泡缩写为一行便于看清，完整文字保留在订单卡和留言区；营业可切换人物近景与全店镜头。

外海扩展为六处连续探索目的地，实体海床与海面同步覆盖边界。追加低多边形阶梯礁、门形遗迹、沉船、灯园、石林与贝壳环礁，新增外海景物使用距离隐藏与关闭阴影控制负担。当前角色与景观仍为程序化风格美术，未使用外部真人动作捕捉或商业角色资产。


## 潜点特色与鱼群疏密

普通鱼群减少并拉开出生间距；高密度旋游鱼群只集中在南潮石林。杰克风暴采用一套原创银色鱼网格、一个MultiMesh批次绘制420个实例，按游戏时钟旋游和摆尾，暂停冻结。

琥珀珊瑚礁新增约90×75米的珊瑚花园：150簇、四种原创网格形态、八种配色，使用四个MultiMesh批次绘制，贴合海床并留出弯曲通道。
