## V0.4 需求与已实现行为

本轮扩大摆放操作空间、提高家具模型细节，并为每类家具提供三个实际不同的款式和价位。以下需求已对应实现，并完成最终联合回归与画面检查；证据见本节末。后文V0.3测试仅代表上一版。

- **扩大实体地面**：可摆放区域从12.6×7.85扩大到20.6×11.85，面积约为原来的2.47倍。场景地板、边界、家具落点验证与顾客位置使用同一空间尺度，旧档已有家具保留有效位置。
- **扩大操作视口**：保留宽320的单侧左栏，移除右侧常驻面板。标准编辑区为Rect2(332,96,1100,708)；Tab折叠侧栏后为Rect2(8,96,1424,708)。坐标基于1440×900设计尺寸，窗口缩放后仍应一致。
- **镜头操作**：鼠标中键拖移、滚轮缩放、F回到中心；Tab展开/折叠侧栏。面板与顶部/底部控制区不得误触地面放置，拖镜头不得误放家具。
- **五类十五款家具**：保留餐桌、绿植、地毯、落地灯、展示架五类，每类包含basic、comfort、premium三款，价格和三维模型确有区别。购买前能识别类别、款式与价格，收纳列表保留款式信息。
- **模型细节**：款式差别包含形体、部件或材质细节，不能仅改名称或售价；维持原创低多边形风格，放置预览应与对应款式一致。
- **事务一致**：不同款式的购买、移动、配色、保存、取消和撤销沿用草稿机制；保存一次统一扣款，取消不改真实金币或玩家存档，变体不能在保存后丢失或变成基础款。
- **兼容与边界**：旧档未记录variant的家具迁移为basic，保留所有权、位置和装修赠品。装修解锁、经营席位上限、中央通道与实体防重叠规则继续生效。具体款式价格及模型差异以本轮经济和美术配置为准。

## V0.3 已交付基线（历史）
版本：V0.3；日期：2026-10-22。本轮在已有潜水与餐厅经营基础上增加自由布置，不改变六项基础装修的建设与经营解锁规则。

## 目标与范围

清理旧店后，玩家可以自己摆放桌椅、绿植、地毯、落地灯和展示架，旋转家具、选择配色，并更换墙面和地板样式。位置变化会反映在实际三维店面和顾客座位上。

编辑使用草稿：移动、收纳、购买和样式变更都先在草稿中预览；点击“保存布局”后才统一提交金币变化与布局并存档。取消会完整恢复编辑前的布局、家具所有权、样式和金币。

## 玩家操作

1. 在餐厅完成“清理与修复”，进入布置模式。
2. 选择已拥有、处于收纳中的家具，点击地面放置；需要新家具时在布置商店选购，购买先计入草稿。
3. 点击场景中的家具选中，使用移动按钮或按 **G** 重新摆放；按 **R** 每次旋转90度。
4. 按 **Delete** 将选中的家具收回收纳；配色按钮在三种配色之间切换。
5. 墙面、地板各提供三种样式，可在布置界面切换。
6. 满意后点击“保存布局”；不想保留本轮修改时点击“取消”。**Ctrl+Z** 可撤销最近操作，滚轮可缩放布置视图。

正在选择落点时，右键或 Esc 取消这一次摆放，其他草稿修改保留；未在放置时按 Esc 则取消整个布置草稿。

放置按0.5格吸附。半透明绿色预览表示当前位置可放置；红色表示越界、实体家具重叠或占用中央通道，界面会显示原因。地毯允许放在桌下。

## 家具与经营

| 类型 | 用途 |
| --- | --- |
| 桌椅 | 提供实际顾客座位，位置与朝向影响顾客三维展示 |
| 绿植 | 可移动的室内装饰 |
| 地毯 | 地面装饰，可与桌椅叠放 |
| 落地灯 | 可移动的灯具装饰 |
| 展示架 | 可移动的收纳陈设 |

家具价格以布置界面为准。额外购买不替代基础厨房、基础桌椅等建设前置，也不自动增加原有经营加成。

营业人数由实际摆出的桌椅和经营席位上限共同决定：基础桌椅最多同时服务2位，扩座后最多4位；可以只摆1张桌，但至少要有1张已放置桌椅才能开业。把桌子全部收起来后，需要重新放置才能营业。

## 收纳、还原与存档

- 收纳不出售家具、不退款；之后可再次放置。
- 默认还原只把已拥有的装修套装赠品摆回默认位置，额外购入家具放回收纳，不购买、不出售、不退钱；家具配色与墙地板样式保留。
- 未保存的编辑不会改动真实金币、食材库存或已存档布局；取消时全部放弃。
- 保存时统一提交草稿，避免取消布局却已经扣钱。
- 旧档迁移按已购买装修补齐对应赠品，保留原有金币、装备、仓库和经营记录。
- 营业中不能布置；编辑草稿时不能绕过界面开始潜水、营业或执行其他交易。
- 所有存档、日志、缓存和测试产物仍保留在项目目录，不写入 C 盘。

## 验收重点

1. 未清理不能进入；清理后可进入，营业中不可进入。
2. 进入编辑后修改草稿不会触及真实金币、库存与布局；取消完整恢复。
3. 购买后保存只扣一次钱；重复保存不会重复扣钱，余额不足不产生家具。
4. 0.5格吸附、旋转、边界、实体碰撞和中央通道规则一致；桌下地毯合法。
5. 移动、旋转、收纳、配色、墙地板样式都能保存并正确重建三维场景。
6. 收起全部桌椅后不能营业，摆回1张后可营业；顾客跟随实际桌位。
7. 默认还原保留所有权和总支出，赠品回原位、额外家具入收纳。
8. 新旧存档与现有潜水、餐厅流程继续可用，测试不改真实玩家存档。
