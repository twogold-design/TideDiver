# V0.6 千米海域与九种鱼渔猎

## 海域

可游范围为 x/z ±500米、深度上限120米。地形包含近岸陆架、沙坡、海沟、珊瑚礁和环礁，显示网格和实体碰撞共用4米网格高度插值。海面及景观延伸至边界外200米。

保留近岸33条鱼，六处外海地标各24条鱼，航道上有8群、每群9条鱼，共249条。共有53个采集点：近岸11个，每处外海地标提供2颗珍珠、1只宝箱、1瓶气瓶，前往地标的途中另设3瓶气瓶。水母共13只。

任意海面均可按F呼叫接驳船。导航显示当前方向、礁区与尚未使用的气瓶；深度尺覆盖0—120米，距离水平边界18米以内提醒转向。

## 操作与机制

- 鼠标瞄准，左键或空格发射；有效射程以潜水员为中心20米，冷却0.95秒。相机视线和潜水员到鱼之间都必须没有实体遮挡。
- 普通鱼发现潜水员后逃离，命中会惊动附近18米内视线未被实体阻挡的鱼。Ctrl慢游速度2.8米/秒、警觉距离降为48%；Shift冲刺速度11.5米/秒、警觉距离增至165%。
- 河豚受惊膨胀，每次命中最多扣1耐久；收缩后有4秒脆弱窗口。鱼叉升级每级提高1点伤害，基础伤害为1。
- 海鳗与灰礁鲨先蓄力1.15秒，并显示预警；随后沿锁定方向冲刺，横向游动可闪避。近身命中分别扣12/18氧气，攻击后恢复并进入冷却。实体地形会截停冲刺。
- 狮子鱼2.5米内的无遮挡接触扣6氧气，并施加6秒中毒，每秒额外扣1.5氧气。伤害共用2.5秒保护间隔，避免同帧重复扣氧。
- 捕获需有足够背包空间；满包时不会消失或重复入库。安全返航入库，救援仍按本次货物价值35%结算。
- Esc暂停同步冻结鱼类状态、摆尾、攻击蓄力、毒伤、伤害冷却与提示计时。再次出航清空中毒和预警，重新生成鱼群。

## 验证与画面
