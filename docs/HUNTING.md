# V0.6 千米海域与九种鱼渔猎

## 海域

可游范围为 x/z ±500米、深度上限120米。地形包含近岸陆架、沙坡、海沟、珊瑚礁和环礁，显示网格和实体碰撞共用4米网格高度插值。海面及景观延伸至边界外200米。

普通海域共有167条可捕获鱼：近岸21条、六处外海地标各16条、8条航道每群5条，以及入水前方5群每群2条。近岸保留前5条新手橘鳍鱼，并覆盖六种鱼。入口保留橘鳍鱼、青背鱼、沙丁鱼、河豚和金枪鱼共五种，横向与前后拉开分布；背景鱼避免叠到入口附近。共有53个采集点：近岸11个，每处外海地标提供2颗珍珠、1只宝箱、1瓶气瓶，前往地标的途中另设3瓶气瓶。水母共13只。

每次出航从近岸和六处外海地标的开放水域中随机选择入水位置，连续两次不选同一区域，各区域内水平偏移不超过8米；船、潜水员、镜头和入水水花同步平移。入水路径与落点以实际物理体积检查避开岩体。危险鱼出生时与落点的水平距离至少42米，水母至少20米。

任意海面均可按F呼叫接驳船。导航显示当前方向、礁区与尚未使用的气瓶；深度尺覆盖0—120米，距离水平边界18米以内提醒转向。

## 潜点特色

- **双门遗迹 · 潮流大峡谷**：峡谷约160米长、谷底较两岸深至少25米；深水段沿弯曲中线向南流动，核心流速0.9米/秒。松开方向键可随流漂行，普通顺游约加快15%，逆游约减慢15%；横游和上浮仍可控制。25米以上无流，25—45米深逐渐增强，离开峡谷或靠近边缘平滑减弱；不增加额外气耗。界面显示流向、漂流/顺流/逆流状态与流速，暂停时水流运动和示意流线同步冻结。

- **南潮石林 · 杰克风暴**：约20米深可见420条银色杰克鱼绕空心旋涡同步游动，鱼群仅出现在这一潜点。此鱼群为观赏景观，不计入可捕获鱼群或仓库；周边仍有普通可捕获鱼。暂停会冻结旋游与摆尾，离开后裁剪绘制。
- **琥珀珊瑚礁 · 珊瑚花园**：约90×75米范围有150簇珊瑚，包含鹿角、桌状、海扇和脑状四种形态、多种配色，根部逐簇贴合真实海床，保留弯曲沙道供潜游。

## 操作与机制

- 鼠标瞄准，左键或空格发射实体鱼钩；速度24米/秒，带尾迹及轻微下坠，总行程20米（包含出手偏移），冷却0.95秒。飞行过程中先碰到鱼身才造成伤害，先碰到实体地形则停止；准星提示不保证命中，快速鱼需要提前量。详见 [V0.7更新](COASTAL_UPDATE.md)。
- 普通鱼发现潜水员后逃离，命中会惊动附近18米内视线未被实体阻挡的鱼。Ctrl慢游速度2.8米/秒、警觉距离降为48%；Shift冲刺速度11.5米/秒、警觉距离增至165%。
- 河豚受惊膨胀，每次命中最多扣1耐久；收缩后有4秒脆弱窗口。鱼叉升级每级提高1点伤害，基础伤害为1。
- 海鳗与灰礁鲨先蓄力1.15秒，并显示预警；随后沿锁定方向冲刺，横向游动可闪避。近身命中分别扣12/18氧气，攻击后恢复并进入冷却。实体地形会截停冲刺。
- 狮子鱼2.5米内的无遮挡接触扣6氧气，并施加6秒中毒，每秒额外扣1.5氧气。伤害共用2.5秒保护间隔，避免同帧重复扣氧。
- 捕获需有足够背包空间；满包时不会消失或重复入库。安全返航入库，救援仍按本次货物价值35%结算。
- Esc暂停同步冻结鱼类状态、摆尾、攻击蓄力、毒伤、伤害冷却与提示计时。再次出航清空中毒和预警，重新生成鱼群。

## 验证与画面

`tests/test_dive_spawns.gd` 使用内存进度验证全部7个随机入水区域、连续不重复、动画与镜头偏移、出生体积避障与备用位置，以及降低密度后每次入水前后至少2种可见鱼、落点30米内普通鱼不超过14条、同群初始间距至少4米；固定种子可重放，不修改玩家存档。

`tests/test_hunting.gd` 使用内存进度和 `tests/temp/hunting.json` 隔离存档，检查九种鱼的捕获、交易、旧档迁移、鱼叉距离、警觉、护甲、中毒、捕食者状态、实体遮挡、暂停、海床碰撞和仓库真实按钮回调。

`tests/capture_hunting.gd` 使用真实游戏模型与UI生成可复现检查画面，不读写玩家存档。带 `-- --gallery` 输出九鱼图鉴，否则输出渔猎界面与仓库第二页。截图中的鱼位置和状态为专用展示布置，不能代替长时间人工游玩验证。
