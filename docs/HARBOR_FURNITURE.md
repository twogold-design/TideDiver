# 渔港餐厅家具换新（2026-10-26）

餐桌增加餐盘、餐巾和调料瓶，保留两个用餐座位的原坐标。餐边柜改为碗碟叠盘、百叶柜门和碎冰鲜鱼；小木船有渐收船首、三层船板、船舷和支架。渔灯包含护笼、提手、灯芯和绳结；凉棚使用木柱、帆布顶、半卷帘及暖灯串。藤编座椅用实际交织杆件形成透空椅背。织物条纹按屏幕导数过滤，减少缩小时的闪烁。

圆桌、餐柜、遮阳帆布和餐具以柔和浅蓝、灰蓝代替亮白；碎冰使用青灰底色和细小冰块，降低反光。精品地毯补充人字织纹、绳纹边、针脚与结穗；双灯庭院灯增加曲臂、链环、铜框灯笼、铆钉和绳结。

布局模式新增Alt+中键拖动：水平360°环绕、20°–85°俯仰；中键平移、滚轮缩放，F恢复默认方向、位置与缩放。转动镜头后地面拾取和平移仍跟随鼠标，右键继续取消摆放或选购。

现有存档的`kind`、`variant`、UID、位置、朝向、配色索引、摆放/收纳及赠品回收状态均沿用；旧家具在原位置显示为同类别同档的新款。各档售价、占地与经营座位上限保持原值，回收仍退50%向上取整。家具功能沿用原规则，展示柜与渔获陈列不消费库存或额外出售食材；长椅和沙发仍是装饰，不增加经营桌位。
