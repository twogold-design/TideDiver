# Tide Diver · 潮间潜客

Godot 4 原创 3D 第三人称潜水与海岸餐厅经营原型。潜入潮汐湾捕获海鱼、寻找珍珠与宝藏；返航将收获入库，选择出售筹钱或留下食材，逐步修复旧店并经营自己的海岸餐厅。

## 启动

项目位置：当前克隆目录（本机为 `E:\TideDiver`）。引擎位置：`D:\tools\Godot-4.7.2`。

双击 **Launch.cmd** 启动游戏；双击 **Editor.cmd** 打开 Godot 项目。

请通过上述入口启动：应用数据与临时目录指向项目 `.runtime/`，日志在 `artifacts/`，导入缓存在 `.godot/`；游戏进度保存在 `saves/progress.json`，备份为同目录 `.bak` 文件。项目产物不写入 C 盘。

## 重新开始游戏

码头左下角点击“重新开始游戏”；潜水时也可按 Esc，在暂停菜单选择该项。确认框会明确提示清空金币、装备、仓库、装修、家具和经营记录；点击“确认重新开始”后从第1天回到码头，新进度会立即保存。取消或按 Esc 保留原进度，不会重开。

新周目的自动存档与备份同步更新，之后关闭再启动会继续新周目。若无法写入存档，会保留原进度并显示原因。正常启动仍自动读取当前进度。

## 潜水操作

| 操作 | 按键 |
| --- | --- |
| 平面游泳 | WASD / 方向键 |
| 下潜 / 上浮 | Q / E |
| 冲刺 | Shift |
| 慢游接近鱼群 | Ctrl |
| 转动视角并瞄准 | 移动鼠标 |
| 发射鱼叉 | 鼠标左键 / 空格 |
| 拾取附近资源 / 水面返航 | F |
| 暂停并释放鼠标 | Esc |
| 音效开关 | M |
| 码头、仓库、装修、菜单与订单 | 点击界面按钮 |

潜水时鼠标被游戏捕获，Esc 可暂停并释放鼠标。捕获的鱼自动进入背包；珍珠、宝藏和应急氧气瓶需靠近后按 F。上浮至约 3 米、出现返航提示时按 F 回到码头。

点击“出发潜水”后，会随机从近岸或六处外海地标附近入水，连续两次不会选到同一区域。船只、起跳动画与镜头一起移动，入水时显示本次地点。潜水员从船尾起跳，伴随水花、气泡和镜头下沉进入水下，约 3 秒后可自由游泳；入水期间不消耗气瓶量，Esc 可暂停。

冲刺和深水会加快气瓶量消耗，碰到水母也会损失气瓶量；应急气瓶可补充 35 点气瓶量。潜水气瓶、背包、鱼叉各有 3 级升级，可在码头购买。

鱼叉射程以潜水员为起点计算，最远 **20 米**，每次发射后冷却 **0.95 秒**。鱼会警觉逃离，命中会惊动附近同伴；Ctrl 慢游降低警觉距离，冲刺则更容易惊动鱼群。河豚膨胀时每次仅受1点伤害，收缩后有4秒进攻窗口；狮子鱼近身会造成中毒；海鳗和灰礁鲨会先预警蓄力，再沿固定方向冲刺，可横向闪避。界面显示猎物耐久、危险预警和中毒倒计时。

带倒钩的鱼叉以 **24米/秒** 实际飞行，带尾迹和轻微下坠；碰到鱼身才造成伤害，岩石会挡住飞行路径。瞄准提示不保证命中，鱼游开会射空，追逐快速鱼时需要提前量。

九种鱼均可捕获、返航入库和出售。橘鳍鱼、青背鱼、灯笼鱼仍可烹饪，六种新鱼暂用于出售；仓库用三页展示全部物资。鱼种、售价与行为见 [渔猎说明](docs/HUNTING.md)。

## 从旧店到第一次开业

1. **潜水筹集物资**：正常返航只把收获存入仓库，不自动增加金币。
2. **进入“我的餐厅”**：仓库支持单件或同类全售；“出售贵重物”只卖珍珠和宝藏，鱼可留作料理。
3. **完成基础装修**：清理与修复 40 G、基础厨房 100 G、基础桌椅 70 G，共 **210 G** 即可试营业。
4. **备菜**：用 + / − 设置份数、选择清爽/香煎/香辣口味；可点“精细备料”，经过4秒清理、切配、腌制增加品质。食材只在开业时预留一次。
5. **营业**：顾客入座后开始制作，在绿色火候区点击翻面；完成后可以精致摆盘，再趁热上菜。备料、火候、摆盘和合口味最高增加25%品质收入，出锅超过8秒则失去品质加成。仍需留意耐心，超时会损失食材。
6. **继续成长**：售罄或完成顾客目标后自动结账，也可提前打烊；未分配给顾客的备料退回仓库。收入可用于装备或进一步装修。

| 料理 | 食材 | 售价 | 制作时间 |
| --- | --- | --- | --- |
| 香煎橘鳍鱼 | 橘鳍鱼 ×1 | 42 G | 3 秒 |
| 海盐青背鱼 | 青背鱼 ×1 | 72 G | 4 秒 |
| 深海灯笼鱼料理 | 灯笼鱼 ×1 | 120 G | 5 秒 |

基础店最多同时接待2位顾客，实际数量取决于已放置桌椅，每场目标4位。招牌增加 2 位目标顾客；扩座增加 2 个座位和 2 位目标顾客；软装增加 8 秒耐心，并给予完成订单 10% 小费（向下取整）。

每个出航日最多营业一次。每次潜水返航或救援推进一天，餐厅结账不推进日期；卖光食材后仍可再次潜水补货。营业时 Esc 暂停，制作和耐心计时都会停止。

## 顾客与主厨表现

潜水员补充了分体面罩、呼吸软管、气瓶绑带与阀门、腕表、分指手套、带筋条的脚蹼和鱼枪部件。餐厅人物采用更细的脸部轮廓、眼睛、耳鼻与手指，增加五种发型、衣领纽扣、布料纹理、口袋、围裙缝线、厨师帽褶皱和鞋底鞋带；原有游泳、料理、品尝与情绪动作继续使用。

顾客会通过桌边气泡和订单卡片表达期待、饥饿或催单，也会评价入味、火候、摆盘、口味偏好和凉菜。主厨在备料及做菜时工作；摆盘会为出餐盘添加柠檬和香草。账单区分“满意 / 待改进 / 未吃到”，记录拿手菜、合口味、凉菜和品质增收，随上次账单保存。营业暂停冻结火候、温度、耐心和人物动作；顶部可切换近景或全店视角。

## 更大的连续海域

海域扩大至 **1000×1000米**，深度上限 **120米**，海床包含陆架、起伏沙坡和海沟。近岸之外可探索双门遗迹、幽蓝灯园、远航沉船、琥珀珊瑚礁、南潮石林和月贝环礁。普通海域共有167条可捕获鱼、53个采集点和13只水母，近岸覆盖六种鱼，每次入水前方分散刷新10条浅水鱼，包含橘鳍鱼、青背鱼、沙丁鱼、河豚和金枪鱼；普通鱼群拉开间距，危险鱼与水母避开入水位置。双门遗迹新增约160米长的潮流大峡谷，深水段向南缓流，停游会漂行、顺游加速、逆游有轻微阻力，横游和上浮不受限制。南潮石林设有局部旋游的“杰克风暴”观赏鱼群；琥珀珊瑚礁铺有约90×75米、150簇珊瑚的连片花园，保留可游通道。远航途中设置补氧点。左侧导航标记你的位置、方向和可用气瓶；临近边缘会提示洋流增强。上浮后可在任意海面呼叫接驳船。

## GM 自选潜点测试

在码头或潜水时按 **F1**，也可点击码头或暂停菜单中的 **“GM 自选潜点”**。七个潜点均提供 **“船上入水”**（播放原有入水动画）和 **“直达景观”**（直接到水下观察位置）；峡谷直达位置位于流场内，珊瑚花园和杰克风暴也可直接查看。面板打开时潜水暂停，按 **Esc / F1** 或关闭按钮恢复原状态。

码头选点会开始一次潜水；水下切点沿用当前潜水，保留背包、气瓶量和已捕获/采集状态，不推进日期或触发结算。选点本身不写存档，正常返航仍按原规则保存进度。普通“出发潜水”继续随机选择入水点。

## 自由布置店面

完成清理后进入布置模式，可购入、放置和收纳餐桌、绿植、地毯、渔灯、餐边柜、长椅、遮阳设施与渔港摆件，**每类三档，共24款**。当前已换成统一的渔港小餐厅系列：拼板木桌、藤编餐椅、海蓝条纹软座、陶缸棕榈、船用渔灯、碗碟架、冰鲜展示柜、卷帘凉棚、鲜鱼黑板、渔获箱与小木船陈列台。完整目录见[渔港家具换新](docs/HARBOR_FURNITURE.md)。旧档家具在原位置显示对应新款，价格、占地和座位规则保持不变。在左侧商店选类别和款式；“我的家具”查看已拥有及收纳的家具。点击家具选中，按 **G** 移动、**R** 旋转90度、**Delete** 半价回收；界面可改家具配色和墙地板样式，**Ctrl+Z** 撤销，滚轮缩放；**中键拖动**时地面跟随鼠标，**Alt+中键拖动**旋转和调整俯仰，**F**恢复默认视角，**Tab**折叠/展开左侧栏。

餐厅海岸增加弯曲潮线、干湿沙地、动态浪花与细浪、棕榈羽叶、礁石、草簇、贝壳、漂木和系泊小艇。固定海岸景物位于布置地面之外，室内家具仍由玩家摆位决定。

可摆放地面扩大到20.6×11.85，约为原来的2.47倍；界面保留单侧左栏，折叠后获得更宽操作视野。家具按0.5格吸附，绿色预览可以放置，红色会说明越界、重叠或占用通道的原因；地毯可铺在桌下。旋转不会被边界卡住：新朝向在原位置放不下时进入旋转预览，可继续转向或移到合法位置再放下；右键取消保留原摆位。选购先预留草稿金币，**成功放下并保存布局**才购买；右键或Esc取消待购会退回预留金币，保存时也不会购买尚未放下的家具。取消整个布局保留原金币和布局。已拥有家具点击“回收”或按Delete，退还对应款式售价的 **50%，向上取整**（25 G退13 G），保存布局后到账；已摆、收纳及装修赠品均可回收，回收后不再拥有该件。退款可撤销，取消整个布局保留原金币和布局。“仅收纳”保留家具供以后重新摆放。默认还原把尚未回收的套装赠品归位，额外购买家具收纳，保留配色与墙地板样式；已回收赠品不会通过还原、返航或重载重新生成。

增设雅座赠送2套餐桌，默认位置被占时会自动寻找合法空位；实在放不下则进入“我的家具”收纳并给出提示。海洋软装赠送的2盆绿植和2张地毯默认收纳，由你决定摆放位置；不会额外生成不可管理的露台盆栽。“我的家具”标明待放置、已摆、收纳及赠品来源。

至少摆放1张桌才能开业，顾客会坐到你实际摆放的位置。基础/扩座经营上限仍为2/4位。完整规则和验证见 [自由布置说明](docs/FREE_DECORATION.md)。

## 进度与救援

正常返航、出售、装修、装备升级和营业操作会保存进度。旧版存档保留已有金币、装备、仓库、装修和经营记录；缺少家具款式的旧家具按基础款迁移。

潜水救援将**本次背包货物**按价值的 35% 折成金币（向下取整），不入仓库，也不影响岸上库存和装修。

营业中关闭游戏后，重新启动会结束上次营业：已完成订单收入保留，未分配备料退库，已分配未完成订单记流失，当日不能再次开业。未结束的潜水不单独保存，退出前请先返航。
