# Tide Diver · 潮间潜客

Godot 4 原创 3D 第三人称潜水与海岸餐厅经营原型。潜入潮汐湾捕获海鱼、寻找珍珠与宝藏；返航将收获入库，选择出售筹钱或留下食材，逐步修复旧店并经营自己的海岸餐厅。

## 启动

项目位置：`M:\NewGames\TideDiver`。引擎位置：`D:\tools\Godot-4.7.2`。

双击 **Launch.cmd** 启动游戏；双击 **Editor.cmd** 打开 Godot 项目。

请通过上述入口启动：应用数据与临时目录指向项目 `.runtime/`，日志在 `artifacts/`，导入缓存在 `.godot/`；游戏进度保存在 `saves/progress.json`，备份为同目录 `.bak` 文件。项目产物不写入 C 盘。

## 重新开始游戏

码头左下角点击“重新开始游戏”；潜水时也可按 Esc，在暂停菜单选择该项。确认框会明确提示清空金币、装备、仓库、装修、家具和经营记录；点击“确认重新开始”后从第1天回到码头，新进度会立即保存。取消或按 Esc 保留原进度，不会重开。

新周目的自动存档与备份同步更新，之后关闭再启动会继续新周目。若无法写入存档，会保留原进度并显示原因。正常启动仍自动读取当前进度。

## 潜水操作

| 操作 | 按键 |
| --- | --- |
| 平面游泳 | WASD / 方向键 |
| 下潜 / 上浮 | Q / E |
| 冲刺 | Shift |
| 慢游接近鱼群 | Ctrl |
| 转动视角并瞄准 | 移动鼠标 |
| 发射鱼叉 | 鼠标左键 / 空格 |
| 拾取附近资源 / 水面返航 | F |
| 暂停并释放鼠标 | Esc |
| 音效开关 | M |
| 码头、仓库、装修、菜单与订单 | 点击界面按钮 |

潜水时鼠标被游戏捕获，Esc 可暂停并释放鼠标。捕获的鱼自动进入背包；珍珠、宝藏和应急氧气瓶需靠近后按 F。上浮至约 3 米、出现返航提示时按 F 回到码头。

冲刺和深水会增加氧耗，碰到水母也会损失氧气；应急氧气瓶可补充 35 点氧气。氧气瓶、背包、鱼叉各有 3 级升级，可在码头购买。

鱼叉射程以潜水员为起点计算，最远 **20 米**，每次发射后冷却 **0.95 秒**。鱼会警觉逃离，命中会惊动附近同伴；Ctrl 慢游降低警觉距离，冲刺则更容易惊动鱼群。河豚膨胀时每次仅受1点伤害，收缩后有4秒进攻窗口；狮子鱼近身会造成中毒；海鳗和灰礁鲨会先预警蓄力，再沿固定方向冲刺，可横向闪避。界面显示猎物耐久、危险预警和中毒倒计时。

九种鱼均可捕获、返航入库和出售。橘鳍鱼、青背鱼、灯笼鱼仍可烹饪，六种新鱼暂用于出售；仓库用三页展示全部物资。鱼种、售价与行为见 [渔猎说明](docs/HUNTING.md)。

## 从旧店到第一次开业

1. **潜水筹集物资**：正常返航只把收获存入仓库，不自动增加金币。
2. **进入“我的餐厅”**：仓库支持单件或同类全售；“出售贵重物”只卖珍珠和宝藏，鱼可留作料理。
3. **完成基础装修**：清理与修复 40 G、基础厨房 100 G、基础桌椅 70 G，共 **210 G** 即可试营业。
4. **备菜**：在菜单中用 + / − 设置份数，每份消耗一条对应鱼；至少准备一份。
5. **营业**：顾客入座后点击“制作”，等待完成再点“上菜”。留意耐心条，超时会损失已分配食材且没有收入。
6. **继续成长**：售罄或完成顾客目标后自动结账，也可提前打烊；未分配给顾客的备料退回仓库。收入可用于装备或进一步装修。

| 料理 | 食材 | 售价 | 制作时间 |
| --- | --- | --- | --- |
| 香煎橘鳍鱼 | 橘鳍鱼 ×1 | 42 G | 3 秒 |
| 海盐青背鱼 | 青背鱼 ×1 | 72 G | 4 秒 |
| 深海灯笼鱼料理 | 灯笼鱼 ×1 | 120 G | 5 秒 |

基础店最多同时接待2位顾客，实际数量取决于已放置桌椅，每场目标4位。招牌增加 2 位目标顾客；扩座增加 2 个座位和 2 位目标顾客；软装增加 8 秒耐心，并给予完成订单 10% 小费（向下取整）。

每个出航日最多营业一次。每次潜水返航或救援推进一天，餐厅结账不推进日期；卖光食材后仍可再次潜水补货。营业时 Esc 暂停，制作和耐心计时都会停止。

## 顾客与主厨表现

顾客会通过桌边气泡和订单卡片表达期待、饥饿或催单。主厨随订单进行料理与出餐动作；顾客在完成服务后有用餐、感谢或失望离店表现。左侧保留最近3条顾客留言；账单区分“满意 / 等餐较久 / 未吃到”，并给出改进建议，评价随上次账单保存。营业暂停也会冻结人物动作。营业顶部“近看人物 / 全店视角”可切换镜头，方便查看动作或照看远处桌位。

## 更大的连续海域

海域扩大至 **1000×1000米**，深度上限 **120米**，海床包含陆架、起伏沙坡和海沟。近岸之外可探索双门遗迹、幽蓝灯园、远航沉船、琥珀珊瑚礁、南潮石林和月贝环礁。全海域有249条鱼、53个采集点和13只水母，远航途中设置补氧点。左侧导航标记你的位置、方向和可用气瓶；临近边缘会提示洋流增强。上浮后可在任意海面呼叫接驳船。

## 自由布置店面

完成清理后进入布置模式，可购入、放置和收纳桌椅、绿植、地毯、落地灯与展示架，**每类提供三种不同价位和模型的款式，共15款**。在左侧“家具商店”选类别和款式；“我的家具”查看已拥有及收纳的家具。点击家具选中，按 **G** 移动、**R** 旋转90度、**Delete** 收回；界面可改家具配色和墙地板样式，**Ctrl+Z** 撤销，滚轮缩放；**中键拖动**平移镜头，**F**回到中心，**Tab**折叠/展开左侧栏。

可摆放地面扩大到20.6×11.85，约为原来的2.47倍；界面保留单侧左栏，折叠后获得更宽操作视野。家具按0.5格吸附，绿色预览可以放置，红色会说明越界、重叠或占用通道的原因；地毯可铺在桌下。购买与编辑都先在草稿中进行，**保存布局**才统一扣款并存档，**取消**保留原金币和布局。收纳不退款；默认还原把已有套装赠品归位，额外购买家具收纳，保留配色与墙地板样式。

至少摆放1张桌才能开业，顾客会坐到你实际摆放的位置。基础/扩座经营上限仍为2/4位。完整规则和验证见 [自由布置说明](docs/FREE_DECORATION.md)。

## 进度与救援

正常返航、出售、装修、装备升级和营业操作会保存进度。旧版存档保留已有金币、装备、仓库、装修和经营记录；缺少家具款式的旧家具按基础款迁移。

潜水救援将**本次背包货物**按价值的 35% 折成金币（向下取整），不入仓库，也不影响岸上库存和装修。

营业中关闭游戏后，重新启动会结束上次营业：已完成订单收入保留，未分配备料退库，已分配未完成订单记流失，当日不能再次开业。未结束的潜水不单独保存，退出前请先返航。

## 版本与验证

当前V0.6接入九种原创低多边形鱼类模型、反应式渔猎、千米海域与仓库分页；保留角色动作、顾客反馈、餐厅经营及五类十五款家具的自由布置。

厨房和招牌仍为固定建设，不支持自由移动或家具退款。员工招聘、复杂烹饪小游戏、剧情、独立海域切换、联网和独立发行包属于后续方向。

当前十套测试共 **748项通过**（22+59+52+53+61+165+103+51+55+127），覆盖九种鱼捕获与存档、警觉/护甲/中毒/捕食者、遮挡与暂停、仓库分页以及原有潜水餐厅玩法。实际画面已检查鱼类模型、渔猎提示和新增仓库页。双击 **Test.cmd** 可复测，完整证据见 [验证记录](docs/TESTING.md)。
