# 潮间潜客 · 完整网页工程

根目录的 `index.html` 可直接作为比赛平台入口。此目录同时包含可修改、可重新构建的全部游戏源码、素材、网页模板、Web 导出模板与测试。

多人开发请先阅读 [协作开发说明](CONTRIBUTING.md)，包含环境配置、文件分工、旧路径迁移和提交前检查。

## 目录

| 路径 | 用途 |
| --- | --- |
| `index.html`、`index.js`、`index.wasm`、`index.pck`、音频脚本 | 可直接部署的网页游戏 |
| `local-loader.js`、`local-data.js` | 双击 HTML 时使用的本地加载器与压缩资源；网站模式不下载重复资源 |

| `src/web/templates/` | 匹配 Godot 4.7.2 的单线程 Web 导出模板 |
| `src/export_presets.cfg` | 网页导出配置 |
| `src/tests/` | 游戏逻辑和真实浏览器回归检查 |
| `tools/`、根目录 `.cmd`、`package.json` | 构建、本地预览、测试与完整工程打包 |

## 运行和修改

- **双击试玩**：完整解压工程后，直接双击根目录 `index.html`，用新版 Edge / Chrome 打开，点击“启程”即可游玩。无需 Node.js、服务器或联网。
- **网站模式试玩**：安装 Node.js 后双击 `Launch.cmd`，自动启动本地服务并打开浏览器；重复双击会复用服务。也可运行 `npm start` 后访问 `http://127.0.0.1:8060/`。比赛平台直接托管完整目录即可。
- **编辑**：用 Godot **4.7.2** 打开 `src/project.godot`。三维场景和玩法在 `src/scripts/` 修改，网页外壳在 `src/web/shell.html` 修改。
- **重新构建**：安装 Node.js 后运行 `BuildWeb.cmd`，覆盖根目录网页文件，并重新打包双击启动所需的本地资源。编辑器路径可用 `BuildWeb.cmd -Godot "编辑器完整路径"` 或环境变量 `GODOT_BIN` 指定。已内置匹配的 Web 模板，无需另行下载。
- **逻辑验证**：运行 `Test.cmd`。浏览器检查先安装开发依赖 `npm ci`；`npm run test:local` 验证直接打开 HTML，`npm run test:web` 验证网站模式（需要先启动预览服务器）。默认使用本机 Edge，可通过 `TIDE_BROWSER_CHANNEL` 指定其他已安装 Chromium 通道。
- **完整工程打包**：运行 `npm run package`，或 `BuildWeb.cmd -Package`。压缩包生成在项目目录外的 `TideDiver-Web.zip`，包含源码与运行文件，`index.html` 位于压缩包根目录。

构建工具需要外部安装 Godot 编辑器，未将编辑器程序装入参赛工程。导出只使用单线程 WebGL 2，不需要特殊跨域响应头。本地双击模式通过 `local-data.js` 读取压缩资源，HTTP/HTTPS 模式直接读取 WASM/PCK。完整游戏没有 CDN 字体、远程素材或后端服务依赖。

## 存档与体积

浏览器进度保存在当前站点的 IndexedDB 中，不包含任何旧玩家存档。旧桌面运行数据没有恢复。构建日志和临时导出写入项目同级的隐藏工作目录；Godot 导入缓存、测试临时数据、Git 历史、Node 开发依赖不进入参赛压缩包。

本地文件模式和网站模式的存档各自独立。请固定浏览器和打开方式继续游玩。

打包脚本分别校验完整工程和 ZIP 均小于 **200,000,000 字节**。上传整个压缩包即可同时提供网页入口与源代码。后续更改应重新构建再打包。

## 潜水动作与海底细节

**A / D** 左右侧游时，潜水员会侧倾、侧向蹬蹼并用手臂平衡；**S** 后退采用双腿收放的反向划蹼。方向切换和松键会平滑过渡，斜向游动可混合动作；暂停冻结姿态，重新入水或GM切点会清除旧姿态。

沙地增加随坡面变化的细沙、波纹和沉积层；岩石改用多款侵蚀轮廓与细裂纹。珊瑚补充分枝末端、珊瑚杯、扇枝和脑纹，贝壳增加径向沟纹与瓣缘，海草改用弯曲叶片，并在七个潜点分散放置海星和管海绵。细碎石与海床生物使用共享网格、分区批次和距离裁剪；新增装饰不参与捕鱼或采集，也不增加阻挡。

动作与细节版本的17套游戏回归共1879项通过，网页完整流程及A/D/S操作检查通过；已实际查看方向动作和近岸、珊瑚、环礁、峡谷画面。

## 潜点外围探索

七个潜点围绕原主景扩展到68—74米探索半径，每处都有两处外围景观点，可寻找草坡与贝床、岩岸遗迹、幽光花圃、沉船散落货舱、珊瑚外礁与海扇长廊、石柱沙谷及外环贝床。导航显示潜点范围、◇支路和最近景点距离，到达后显示地点名称。

每处新增两项外围采集和一个补气点，海域采集/补气总数由53增加到74。普通鱼总数仍为167条，鱼与海床细节分散到更大的范围；入水位置、GM选点、原有峡谷水流、杰克风暴和珊瑚花园继续保留。

扩展后18套游戏回归共2006项通过，包含14处支点的实际通行、资源交互、导航名称与鱼群分布检查；网页完整流程通过，根目录网页已重新构建。
