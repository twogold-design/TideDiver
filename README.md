# Tide Diver · 潮间潜客

Godot 4 原创 3D 第三人称潜水与海岸餐厅经营原型。潜入潮汐湾捕获海鱼、寻找珍珠与宝藏；返航将收获入库，选择出售筹钱或留下食材，逐步修复旧店并经营自己的海岸餐厅。

## 启动

项目位置：`M:\NewGames\TideDiver`。引擎位置：`D:\tools\Godot-4.7.2`。

双击 **Launch.cmd** 启动游戏；双击 **Editor.cmd** 打开 Godot 项目。

请通过上述入口启动：应用数据与临时目录指向项目 `.runtime/`，日志在 `artifacts/`，导入缓存在 `.godot/`；游戏进度保存在 `saves/progress.json`，备份为同目录 `.bak` 文件。项目产物不写入 C 盘。

## 潜水操作

| 操作 | 按键 |
| --- | --- |
| 平面游泳 | WASD / 方向键 |
| 下潜 / 上浮 | Q / E |
| 冲刺 | Shift |
| 转动视角并瞄准 | 移动鼠标 |
| 发射鱼叉 | 鼠标左键 / 空格 |
| 拾取附近资源 / 水面返航 | F |
| 暂停并释放鼠标 | Esc |
| 音效开关 | M |
| 码头、仓库、装修、菜单与订单 | 点击界面按钮 |

潜水时鼠标被游戏捕获，Esc 可暂停并释放鼠标。捕获的鱼自动进入背包；珍珠、宝藏和应急氧气瓶需靠近后按 F。上浮至约 3 米、出现返航提示时按 F 回到码头。

点击“出发潜水”后，潜水员从船尾起跳，伴随水花、气泡和镜头下沉进入水下，约 3 秒后可自由游泳；入水期间不消耗气瓶量，Esc 可暂停。

冲刺和深水会加快气瓶量消耗，碰到水母也会损失气瓶量；应急气瓶可补充 35 点气瓶量。潜水气瓶、背包、鱼叉各有 3 级升级，可在码头购买。

## 从旧店到第一次开业

1. **潜水筹集物资**：正常返航只把收获存入仓库，不自动增加金币。
2. **进入“我的餐厅”**：仓库支持单件或同类全售；“出售贵重物”只卖珍珠和宝藏，鱼可留作料理。
3. **完成基础装修**：清理与修复 40 G、基础厨房 100 G、基础桌椅 70 G，共 **210 G** 即可试营业。
4. **备菜**：在菜单中用 + / − 设置份数，每份消耗一条对应鱼；至少准备一份。
5. **营业**：顾客入座后点击“制作”，等待完成再点“上菜”。留意耐心条，超时会损失已分配食材且没有收入。
6. **继续成长**：售罄或完成顾客目标后自动结账，也可提前打烊；未分配给顾客的备料退回仓库。收入可用于装备或进一步装修。

| 料理 | 食材 | 售价 | 制作时间 |
| --- | --- | --- | --- |
| 香煎橘鳍鱼 | 橘鳍鱼 ×1 | 42 G | 3 秒 |
| 海盐青背鱼 | 青背鱼 ×1 | 72 G | 4 秒 |
| 深海灯笼鱼料理 | 灯笼鱼 ×1 | 120 G | 5 秒 |

基础店最多同时接待2位顾客，实际数量取决于已放置桌椅，每场目标4位。招牌增加 2 位目标顾客；扩座增加 2 个座位和 2 位目标顾客；软装增加 8 秒耐心，并给予满意订单 10% 小费（向下取整）。

每个出航日最多营业一次。每次潜水返航或救援推进一天，餐厅结账不推进日期；卖光食材后仍可再次潜水补货。营业时 Esc 暂停，制作和耐心计时都会停止。

## 自由布置店面

完成清理后进入布置模式，可购入、放置和收纳桌椅、绿植、地毯、落地灯与展示架。点击家具选中，按 **G** 移动、**R** 旋转90度、**Delete** 收回；界面可改家具配色和墙地板样式，**Ctrl+Z** 撤销，滚轮缩放。

家具按0.5格吸附，绿色预览可以放置，红色会说明越界、重叠或占用通道的原因；地毯可铺在桌下。购买与编辑都先在草稿中进行，**保存布局**才统一扣款并存档，**取消**保留原金币和布局。收纳不退款；默认还原把已有套装赠品归位，额外购买家具收纳，保留配色与墙地板样式。

至少摆放1张桌才能开业，顾客会坐到你实际摆放的位置。基础/扩座经营上限仍为2/4位。完整规则和验证见 [自由布置说明](docs/FREE_DECORATION.md)。

## 进度与救援

正常返航、出售、装修、装备升级和营业操作会保存进度。旧版存档保留金币、潜水装备和探索记录，并新增空仓库与未装修店面。

潜水救援将**本次背包货物**按价值的 35% 折成金币（向下取整），不入仓库，也不影响岸上库存和装修。

营业中关闭游戏后，重新启动会结束上次营业：已完成订单收入保留，未分配备料退库，已分配未完成订单记流失，当日不能再次开业。未结束的潜水不单独保存，退出前请先返航。

## 版本与验证

V0.2 包含一张三维海域、三种鱼、仓库售货、六项装修、三种料理、顾客订单与营业结算。模型和基础音效由程序生成；员工招聘、复杂烹饪小游戏、剧情、多海域、联网和独立发行包属于后续方向。V0.3增加自由布置：家具移动/旋转/收纳、配色、墙地板样式，以及可保存或取消的布局草稿。

V0.3 六套联合测试共 **294项通过**（22+59+52+53+61+47），并实际查看了旧店、装修、菜单、营业、账单、返航明细和自由布置画面。双击 **Test.cmd** 可复测，测试不会修改玩家存档。完整证据与验证边界见 [验证记录](docs/TESTING.md) 和 [餐厅验收记录](docs/RESTAURANT_ACCEPTANCE.md)。

V0.3 自由布置新增专项已通过 **61项数据检查 + 47项实际场景与鼠标流程检查**。当前提供五种家具、0.5格吸附、90度旋转；厨房和招牌仍为固定建设，不支持自由移动或家具退款。全部专项与原有功能回归已经由 Test.cmd 联合运行通过，真实玩家存档前后哈希一致。
