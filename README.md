# 潮间潜客 · 完整网页工程

根目录的 `index.html` 可直接作为比赛平台入口。此目录同时包含可修改、可重新构建的全部游戏源码、素材、网页模板、Web 导出模板与测试。

多人开发请先阅读 [协作开发说明](CONTRIBUTING.md)，包含环境配置、文件分工、旧路径迁移和提交前检查。

## 目录

| 路径 | 用途 |
| --- | --- |
| `index.html`、`index.js`、`index.wasm`、`index.pck`、音频脚本 | 可直接部署的网页游戏 |
| `local-loader.js`、`local-data.js` | 双击 HTML 时使用的本地加载器与压缩资源；网站模式不下载重复资源 |

| `src/web/templates/` | 匹配 Godot 4.7.2 的单线程 Web 导出模板 |
| `src/export_presets.cfg` | 网页导出配置 |
| `src/tests/` | 游戏逻辑和真实浏览器回归检查 |
| `tools/`、根目录 `.cmd`、`package.json` | 构建、本地预览、测试与完整工程打包 |

## 运行和修改

- **双击试玩**：完整解压工程后，直接双击根目录 `index.html`，用新版 Edge / Chrome 打开，点击“启程”即可游玩。无需 Node.js、服务器或联网。
- **网站模式试玩**：安装 Node.js 后双击 `Launch.cmd`，自动启动本地服务并打开浏览器；重复双击会复用服务。也可运行 `npm start` 后访问 `http://127.0.0.1:8060/`。比赛平台直接托管完整目录即可。
- **编辑**：用 Godot **4.7.2** 打开 `src/project.godot`。三维场景和玩法在 `src/scripts/` 修改，网页外壳在 `src/web/shell.html` 修改。
- **重新构建**：安装 Node.js 后运行 `BuildWeb.cmd`，覆盖根目录网页文件，并重新打包双击启动所需的本地资源。编辑器路径可用 `BuildWeb.cmd -Godot "编辑器完整路径"` 或环境变量 `GODOT_BIN` 指定。已内置匹配的 Web 模板，无需另行下载。
- **逻辑验证**：运行 `Test.cmd`。浏览器检查先安装开发依赖 `npm ci`；`npm run test:local` 验证直接打开 HTML，`npm run test:web` 验证网站模式（需要先启动预览服务器）。默认使用本机 Edge，可通过 `TIDE_BROWSER_CHANNEL` 指定其他已安装 Chromium 通道。
- **完整工程打包**：运行 `npm run package`，或 `BuildWeb.cmd -Package`。压缩包生成在项目目录外的 `TideDiver-Web.zip`，包含源码与运行文件，`index.html` 位于压缩包根目录。

构建工具需要外部安装 Godot 编辑器，未将编辑器程序装入参赛工程。导出只使用单线程 WebGL 2，不需要特殊跨域响应头。本地双击模式通过 `local-data.js` 读取压缩资源，HTTP/HTTPS 模式直接读取 WASM/PCK。完整游戏没有 CDN 字体、远程素材或后端服务依赖。

窗口与全屏使用扩展视野，画面铺满可用区域；`responsive_ui.gd` 管理面板、按钮和弹窗的定位，文字与模型保持等比。高分屏保留原生界面分辨率，`web_platform.gd` 单独限制海景的三维渲染像素，并按餐厅场景调整预算；浏览器控制台的 `window.tideRenderStats` 提供只读帧率和渲染诊断。

餐厅、自由布置的文字和按钮按实际屏幕像素绘制；家具收纳列表保留原生滚动与选择，并同步调整像素字号。`web_smoke.cjs --file --wide --ui-text` 还会检查窗口缩放后的家具列表选择、配色按钮及保存结果。

正常潜水返航立即回到整备界面，居中显示收获入库提示，5 秒后自动消失；提示没有选择按钮，不阻止整备操作。出发页的标题、日志和主要按钮保持统一的左侧留白。

自由布置允许在中央入口区域摆放家具；地板边界与家具重叠检查继续生效。

浅蓝帆布伞、海蓝条纹大伞和果色拼瓣遮阳伞只按底座占地，伞面可以覆盖邻近家具或伸出地板边缘；底座仍须位于地板内且不能与其他家具重叠。放置预览与选中框同样显示底座范围。四柱木架凉棚保留完整占地。

家具商店共 36 款家具，各分类按价格从低到高排列，每类四款同屏展示。果色餐桌、三角梅、柑橘圆毯、彩灯笼、饮品推车、贝壳长椅、拼瓣伞和冲浪板架直接排列在原有分类中。「软装」分类提供三角彩旗（65 G）、贝壳风铃挂帘（95 G）、球泡彩灯（135 G）和藤编灯笼串（195 G），均带细木支架，适合沿入口或围栏摆放。新增家具提供三套明亮柔和的配色，选中后点击「切换配色」；沿用原有购买、半价回收与存档规则。模型由 `furniture_art.gd` 生成，无需外部下载素材。

「开门营业」可用时显示绿色按钮、浅色文字与描边，未满足条件时保持暗色；悬停与按下各有对应颜色。营业页文字保留清晰的像素绘制，订单说明至少 14 像素、操作按钮至少 16 像素，长顾客留言自动换行。

自由布置复用家具网格和拖动预览，只更新位置、旋转及有效性颜色；家具变化不会重新生成海滩与厨房。家具模型缓存最多 24 种，商店预览缓存最多 8 个，避免反复选中、换色时重建全部预览。布局文字在内容变化或窗口调整时重绘，不降低字体或场景分辨率。`profile_layout.gd` 测量独立内存场景中的拖动、商店及房间更新耗时；`web_smoke.cjs --file --wide --summer --ui-text --layout-perf` 记录 Chrome 静止与拖动帧率，并继续验证完整布局、存档和营业流程。加 `--baseline` 可只采集优化前指标，结果保存于工程外工作目录。

`web_smoke.cjs --file --wide --ui-text --summer` 检查各分类新增商品的选购取消与新家具的保存、营业流程；`capture_harbor_furniture.gd -- --summer` 将三套配色的实际模型及商店画面输出到工程外的工作目录。

氧气不足时显示警告；耗尽后先保存结算，再显示救援过程和返航结算，点击“知道了，继续整备”或按 Enter / 空格关闭结算。`src/tests/web_rescue.cjs` 检查真实浏览器救援流程；`web_resolution.cjs`、`web_text.cjs`、`web_performance.cjs` 分别检查窗口适配、文字及性能，`web_smoke.cjs --file --wide` 检查宽窗口下的完整操作流程。

## 存档与体积

浏览器进度保存在当前站点的 IndexedDB 中，不包含任何旧玩家存档。旧桌面运行数据没有恢复。构建日志和临时导出写入项目同级的隐藏工作目录；Godot 导入缓存、测试临时数据、Git 历史、Node 开发依赖不进入参赛压缩包。

本地文件模式和网站模式的存档各自独立。请固定浏览器和打开方式继续游玩。

打包脚本分别校验完整工程和 ZIP 均小于 **200,000,000 字节**。上传整个压缩包即可同时提供网页入口与源代码。后续更改应重新构建再打包。

首页和游戏内统一使用思源黑体 Noto Sans CJK SC Regular；字体说明见 `src/assets/fonts/README.md`，许可见 `FONT-LICENSE.txt`，引擎及依赖许可见 `THIRD-PARTY-NOTICES.txt`。

## 潜水动作与海底细节

**A / D** 左右侧游时，潜水员会侧倾、侧向蹬蹼并用手臂平衡；**S** 后退采用双腿收放的反向划蹼。方向切换和松键会平滑过渡，斜向游动可混合动作；暂停冻结姿态，重新入水或GM切点会清除旧姿态。

沙地增加随坡面变化的细沙、波纹和沉积层；岩石改用多款侵蚀轮廓与细裂纹。珊瑚补充分枝末端、珊瑚杯、扇枝和脑纹，贝壳增加径向沟纹与瓣缘，海草改用弯曲叶片，并在七个潜点分散放置海星和管海绵。细碎石与海床生物使用共享网格、分区批次和距离裁剪；新增装饰不参与捕鱼或采集，也不增加阻挡。

动作与细节版本的17套游戏回归共1879项通过，网页完整流程及A/D/S操作检查通过；已实际查看方向动作和近岸、珊瑚、环礁、峡谷画面。

每处新增两项外围采集和一个补气点，海域采集/补气总数由53增加到74。普通鱼总数仍为167条，鱼与海床细节分散到更大的范围；入水位置、GM选点、原有峡谷水流、杰克风暴和珊瑚花园继续保留。

扩展后18套游戏回归共2006项通过，包含14处支点的实际通行、资源交互、导航名称与鱼群分布检查；网页完整流程通过，根目录网页已重新构建。

## 埋沙鳐鱼、沉船穿行与大峡谷

月贝环礁的“月光沙台”外侧沙地新增六条鳐鱼，平时埋在沙下，靠近后扬起细沙、振动胸鳍并游走，远离潜水员后重新落沙。静潜能靠得更近，冲刺会更早惊动它们。

远航沉船改为真正中空的船体，船首、船尾、左右破洞和顶部舱口均可钻入钻出。舱内分布三百条银蓝小鱼，游动时像星光闪动；近壁镜头自动缩短并避开船体，狭窄处仍能看清前方。GM选择“远航沉船 → 直达景观”会到达船尾入口前。

双门遗迹的大峡谷延长到约280米，槽底宽28米，两岸跨度约92米，岩壁高差超过38米。核心水流提高到2.2米/秒，停游会漂移，顺流明显加速，逆流仍可前进。每次新下潜有35%概率在峡谷中出现一条长尾鲨，潜水中的GM切点不会重抽。

鳐鱼、舱内星光鱼群与长尾鲨属于局部生态景观。潜水中的暂停和GM面板会冻结生态动画；新增功能不修改存档格式。

鳐鱼与沉船版本的20套游戏回归共2087项通过，覆盖实际入口通行、船体与鱼叉阻挡、鳐鱼全身避障和追逐范围、鱼群舱内边界、加强水流与长尾鲨概率。网页完整流程和F1切点、实际游入船舱、暂停恢复、峡谷游动专项通过，无控制台或页面错误；根目录网页资源已重新构建。

## 岩边石头鱼

七个潜点每处随机刷新两条石头鱼，伏在真实岩石边缘，外形和岩纹接近周围石块。平时不巡游或追逐，接触后短暂露出毒棘和鱼鳍，再恢复伪装。触碰会立即扣12点气瓶量，并中毒6秒、每秒额外扣1.5点，配有红闪、音效和刺伤提示；2.5秒免伤避免连续瞬间扣气。石头鱼远离入水落点、采集品和船舱通道，石墙会阻断接触伤害。

可用鱼叉捕获，重量2kg、价值85G，安全返航后存入仓库并可售卖。旧存档自动补齐该鱼库存，原有进度保持。石头鱼替换原分散鱼群中的14个位置，可捕获鱼仍为167条，种类增至10种；观赏鳐鱼、长尾鲨和沉船鱼群继续独立。

石头鱼版本21套游戏回归共2381项通过，包含自然岩边实际射钩捕获、伤害/中毒/免伤、暂停重置和旧存档兼容；已查看伪装和刺伤近景，重新构建后的本地HTML完整浏览器流程通过。

## 深度光照与海底寻宝

环境光、日照、海面反光和水下光束随实际镜头深度平滑减弱，深水逐渐偏暗蓝。潜水灯保留12米内的近处照明，入水时渐变，返航或进入餐厅后恢复岸上光照。

海底新增海玻璃、古硬币、琥珀碎片和海螺，分别占用1、1、1、2kg背包，返航后可按24、48、75、40G售卖。原有74处采集/补气点分布保留，新物品分散替换部分珍珠；原有补气点保持。

宝箱现在随机开出1—3件珍珠、新收集物或应急补气，开箱后显示实际获得的物品、重量与价值。箱盖打开后留在现场，超出背包容量的物品保留在箱内；箱内补气按实际需要领取，余量可在本次潜水中继续领取。同次潜水不会重抽奖励或重复领取。旧存档中的整箱宝藏仍可按原价售卖。

本版本23套游戏回归共2472项通过，包含20/50/90米同一灰色物体的实际渲染亮度、近灯照明范围、开箱部分领取、反馈和旧存档兼容。重新导出的本地HTML完整浏览器流程及宽屏界面检查通过，无页面或控制台错误。
